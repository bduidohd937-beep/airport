# 🛂 AIRPORT: RED ALERT — Prototype V0.1

비대칭 3D 가방 수색 퍼즐 게임의 첫 번째 인터랙티브 프로토타입.

## 설치·실행

Node.js 22 이상 권장.

    git clone https://github.com/bduidohd937-beep/airport.git
    cd airport
    git switch feat/interactive-3d-prototype-v0.1
    npm install
    npm run dev

## 첫 플레이

1. 밀반입팀: 4종 가상 목표물 중 하나를 선택한다.
2. 캐리어의 6개 구획에서 수납 가능한 위치를 선택해 물품을 배치한다.
3. 시작 포인트 7P로 지퍼를 추가한다(첫 단계 1P, 두 번째 2P).
4. 준비 완료를 누르고 화면을 넘긴다. 수색 담당자의 시작 화면은 가려진다.
5. 수색팀: 가방을 회전·확대하고 각 구획의 덮개를 조사한다. 손전등·스캔·가상 절개 도구를 사용할 수 있다.
6. 열린 칸에서 증거 등록으로 물품을 찾는다. 시간이 0이 되거나 가방을 통과시키면 밀반입팀 승리.

## 구성

- Vite + React + TypeScript
- Three.js + React Three Fiber + Drei
- Zustand 상태 관리
- Vitest 규칙 단위 테스트
- 캐리어의 절차적 3D 모델과 패브릭 텍스처, 실시간 라이팅

## 범위

첫 프로토타입은 온라인 멀티플레이가 아닌 **한 화면에서 두 사람이 번갈아 플레이하는 핫시트** 방식이다.

포함: 3D 가방, 여섯 구획, 다층 지퍼 애니메이션, 포인트 편집, 물품 크기 판정, 수색 도구, 타이머, 적발과 승패.

후속: 가방 추가, 실제 자유 배치형 편집, 물품 브러시 디자인, 온라인 협동, 고급 모델링·사운드.

가상 도구와 소품은 실제 공항 보안 절차 또는 보안 우회법을 재현하지 않는다.
